| --- | --- |

| API key | API 官网创建令牌后复制 |
| 请求地址 | `https://ai.axuremart.com/v1` |

### 3、检查一下 config.toml 配置

<Warning>确保 `[model_providers.custom]` 的配置与图中一致，否则无法调用模型。</Warning>

如不一致，到对应路径下找到 `config.toml` 文件修改。文件所在路径：`~/.codex/config.toml`（Windows 为 `C:\Users\你的用户名\.codex\config.toml`）。

```toml
[model_providers.custom]
name = "OpenAI"
wire_api = "responses"
requires_openai_auth = false
http_headers = { "x-openai-actor-authorization" = "local-image-extension" }
base_url = "https://ai.axuremart.com/v1"
experimental_bearer_token = "这里填写你的令牌key"
```
