## 1、编辑器（VSCode / Trae / Cursor）中使用

### 方式一：可视化聊天插件使用（推荐）

1. 确保 codex 插件已安装
2. 点击图标启动

<Frame>
  ![启动 codex 插件](/images/img-25.png)
</Frame>

### 方式二：终端使用

1. 打开终端：编辑器顶部菜单「终端」→「新建终端」
2. 输入启动命令

```bash
codex
```

## 2、ChatGPT 桌面端中使用

1. 确保完成[模型配置](/gpt/config)
2. 打开桌面端，发一条消息测试是否回复。正常回复则配置完毕，无法回复请检查[模型配置](/gpt/config)

<Frame>
  ![桌面端测试](/images/img-26.png)
</Frame>

## 3、image-2 模型生图使用

1. 不需要独立配置 image-2 模型
2. 在 codex 中直接输入：使用 image-2 模型做图

  ![image-2 生图](/images/img-27.png)
