## 1、编辑器（VSCode / Trae / Cursor）终端安装

1. 打开编辑器
2. 点击顶部菜单「终端」→「新建终端」
3. 终端窗口会在 VSCode 底部打开
4. 输入以下命令

```bash
npm install -g @openai/codex
```

<Frame>
  ![终端安装 Codex](/images/img-15.png)
</Frame>

5. 苹果电脑如果遇到权限错误（提示 `errno: -13`），请使用以下命令：

```bash
sudo npm install -g @openai/codex
```

## 2、编辑器（VSCode / Trae / Cursor）可视化插件安装

1. 打开编辑器
2. 找到插件市场
3. 搜索 codex 插件并安装

  ![安装 codex 插件](/images/img-16.png)

## 3、ChatGPT 桌面端下载

1. 打开 GPT 官网：[https://chatgpt.com/codex](https://chatgpt.com/codex)
2. 下载并安装
